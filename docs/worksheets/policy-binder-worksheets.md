# Policy Binder Worksheets

> **Education only.** These worksheets organize *your own paperwork*.
> They never make recommendations. Fill them by hand, in a copied file, or
> on paper — whatever you'll actually maintain.

Print or copy these five worksheets into your binder. Each one maps to a
section of the binder described in guide 11. Keep the originals blank;
fill copies.

---

## Worksheet A — Policy Snapshot (one per policy)

*Guide 03 walks this page line by line. If you fill in only one worksheet
ever, this is the one.*

```

Carrier:            ______________________________
Policy number:      ______________________________
Claim phone number: ______________________________

Policy period:      ____/____/______  to  ____/____/______
Renewal date:       ____/____/______

Premium:            $ ____________  per ( month / six months / year )
Deductible(s):      $ ____________  (standard)
                    $ ____________  (wind/hail or other separate, if any)
                    ____ % of Coverage A  (if a percentage deductible)

Main limit(s):      ________________________________________
                    ________________________________________
                    ________________________________________

Named insured(s):   ________________________________________
Beneficiaries / loss payees (if any): ________________________

Claim-reporting deadline (from conditions section):
                    ______________________________

Notes / questions for the annual call list:
                    ________________________________________
                    ________________________________________
```

## Worksheet C — Claim Log (one line per claim, any size)

*Guide 09. Even small claims get a line; patterns show up here.*

```
| Claim date | Policy | Claim number | What happened (5 words) | Status | Closed date |
| ---------- | ------ | ------------ | ----------------------- | ------ | ----------- |
|            |        |              |                         |        |             |
|            |        |              |                         |        |             |
```

Plus, per open claim, one call-log page:

```
Claim number: ______________

| Date | Who I spoke to | What was said / promised | Next step |
| ---- | -------------- | ------------------------ | --------- |
|      |                |                          |           |
```
