# STATUS

**Project:** insurance-paperwork-decoded-guide
**Owner:** Asdale Dynamics, LLC · **Date:** 2026-10-27
**Scope:** Education-only manual for reading everyday insurance policies.
Never coverage, legal, medical, or tax advice.

## What was built

- **14 markdown guides in `docs/`** (plus this file and the README):
  - `00-start-here.md` — orientation, calm-voice promise, 10-minute first pass
  - `01-how-to-read-a-policy.md` — the seven parts of any policy, three-pass
    reading method, worked micro-example
  - `02-money-math.md` — premiums vs. deductibles vs. out-of-pocket in plain
    arithmetic (copays, coinsurance, limits, worked end-to-end scenarios)
  - `03-declaration-pages.md` — dec-page line-by-line tour, five-number
    exercise, red flags
  - `04-auto.md` … `08-life.md` — per-type translations (auto, renters,
    homeowners, health, life), each with a claim-shaped mental model and an
    annual check
  - `09-claim-filing-walkthrough.md` — universal claim shape, master document
    checklist, three walkthroughs, phone-call discipline
  - `10-denial-letters.md` — what denial letters must contain, four reason
    buckets, appeal-letter skeleton, escalation structure
  - `11-annual-review-ritual.md` — one-hour scripted ritual in ten small
    steps, policy-binder structure, low-energy fallback
  - `12-glossary.md` — ~40 plain-English definitions
  - `worksheets/policy-binder-worksheets.md` — Worksheets A–E (snapshot,
    endorsement log, claim log, home inventory, deadlines/denial tracker)
    plus a binder cover sheet
- **`build.py`** — stdlib-only static site generator (Python 3.8+, no
  dependencies, no network). Renders the markdown subset used by the docs
  (headings, lists, checkboxes, tables, fenced code, blockquotes, inline
  styles, internal links) into `site/`, with a contents nav, prev/next
  paging, per-page disclaimers, and `index.html`.
- **`site/`** — generated static HTML (15 pages). Regenerated by
  `python3 build.py`; git-ignored.
- **`tests/test_build.py`** — 21 unit tests (see below).
- **`README.md`**, **`LICENSE`** (MIT, Copyright (c) 2026 Asdale Dynamics,
  LLC), **`.gitignore`**.

## How to run it

```bash
python3 build.py                              # build site/ from docs/
python3 -m unittest discover -s tests -v      # run the test suite
```

Then open `site/index.html` in any browser, or read `docs/` directly.

## Known gaps

- **Markdown renderer is a subset.** It covers exactly what the docs use.
  Nested lists, setext headings, reference links, and inline images are not
  implemented. New docs must stay inside the supported subset (tests catch
  structure regressions, not unsupported syntax).
- **No search.** The site is browse-only; a client-side search page would be
  a natural next step.
- **Worksheets are text-ASCII**, designed for printing/copying rather than
  interactive forms. A fillable PDF or HTML-form version is future work.
- **Health/Medicare boundary** is handled by reference to the companion
  *medicare-decoded-guide* project, which lives elsewhere.
- **No print stylesheet** beyond reasonable defaults; a dedicated
  `@media print` pass would improve worksheet printing.
- Content is U.S.-flavored (state insurance departments, HO-3 forms, PIP)
  and says so only implicitly.
